# プレーヤーとMP4

`narrate`は`player.html`を、`video`は`presentation.mp4`を`<narration>/`に書き出す。
どちらも原稿・スライド・検査結果は変えない。

## player.html

骨組みは[AppleのHIG](https://developer.apple.com/jp/design/human-interface-guidelines/)（Liquid Glassの浮いた半透明の層、入れ子で揃う角丸、システムの書体、動画プレーヤーの操作）、部品の状態表示・色の役割・フィルターチップは[Material 3](https://m3.material.io/)を参考にしている。どちらの公式テンプレートでもない。
画面はウィンドウいっぱいに広がり、スライドは列の幅と高さに収まる最大の16:9で中央に置く。外観は右上でシステム・ライト・ダークを選べる（ブラウザに記憶する）。

| 領域 | 内容 |
|---|---|
| スライド一覧（左） | PowerPointのように番号・縮小表示・見出しを並べる。選ぶとそのスライドの先頭へ移る。再生中のスライドに枠が付く |
| 中央 | 1600×900のスライドを等比で縮小して表示する。スライドの上に浮く再生操作（再生/一時停止、10秒戻る/進む、前後のスライド、音量、速度0.75〜2倍、全画面）は、再生中にマウスを止めると隠れる。シークバーにはスライドの境目の印が付き、マウスを重ねるとその位置のスライドの縮小表示が出る。スライドをクリックで再生/一時停止、ダブルクリックで全画面 |
| 文字起こし（右） | YouTubeのように、時刻と話している文をスライドごとに並べる。話している文を強調し、自動でスクロールする |

- 文の文字をクリックするとその文の先頭へ移る（一時停止中は位置だけ移る）。時刻のボタンを押すと、その文から再生する。
- 文字はドラッグで選んでコピーできる。選んでいる間は移動しない。
- 検索欄で文を絞り込める。一致しないときは「一致する文はありません」と出る。
- 文字起こしを手でスクロールすると、4秒間は自動スクロールしない。「現在の位置へ」で戻る。
- スライド一覧と文字起こしは、ヘッダーの左端と右側のボタンでそれぞれ閉じたり開いたりできる。閉じるとスライドが広がる。開閉はブラウザに記憶する。
- 全画面は「ウィンドウいっぱい」（T、Escで戻る）と「モニター全体」（F）を選べる。埋め込みのブラウザなどでモニター全体が許可されないときは、ウィンドウいっぱいになる。
- 前回止めた位置から、確認なしで再開する（最後まで聞くと先頭に戻る）。
- `player.html#t=95`のように開くと、95秒の位置から始まる（YouTubeの`t=`と同じ）。前回の位置より優先する。
- 幅1180px以下ではスライド一覧が横並びになり、760px以下では縦1列になる。横スクロールは出ない。
- キー: Space/K 再生・一時停止、←→ 5秒、J/L 10秒、Shift+←→またはPageUp/PageDown 前後のスライド、Home/End 先頭/末尾、M ミュート、F モニター全体、T ウィンドウいっぱい。入力欄やボタンを操作している間は、その部品の標準のキー操作を優先する。

色は`player.html`の先頭にある配色（Palette）で決める。PowerPointのオレンジ4色（`--pp-deep`・`--pp-strong`・`--pp-bright`・`--pp-light`）だけを使い、背景は色を付けない。グラデーションはボタンと進行バーなど操作する部分に限り、38.2%（黄金比）の位置を中間にする。淡い色の濃さは1/φの累乗（14.6%、23.6%）、角丸と余白はフィボナッチ数（5・8・13・21・34）。別の配色にするときはこの4色を差し替える。
アイコンは[Lucide](https://lucide.dev)（v1.49.0、ISCライセンス。一部はFeather由来でMIT）をページ内に埋め込んでいる。ライセンス表記は`player.html`内にある。

文の時刻は、合成したときの実測値（`audio/<id>.json`の`start_frame`/`end_frame`）から計算する。文字数からの推測ではない。
文と文の間の無音では、直前の文を強調したままにする。
`audio/<id>.json`がないスライドは、`narrate`が作り直す。

ダブルクリックで開ける（`file://`）。ローカルのHTTPサーバーで開く場合は、Range要求に対応したものを使う（Pythonの`http.server`は対応していないので、シークできない）。

## presentation.mp4

```powershell
uv run --project "<presenter>/tools" presenter-tts video "<deck>"
```

1. ヘッドレスのChromeかEdgeで各スライドを1枚ずつ撮影する。ブラウザの場所は`PRESENTER_BROWSER`で指定できる。
2. `timeline.json`の長さだけ各スライドを表示し、`narration.wav`と合わせてFFmpegで書き出す。
3. ffprobeで、映像と音声の両方があり、長さが音声と0.1秒以内で一致することを確かめてから、`presentation.mp4`に置き換える。

既定は1920×1080・30fps・H.264（yuv420p、faststart）・AAC 192kbps。`--width`と`--fps`で変えられる。出力先は`--output`。
映像はスライドの静止画を切り替える。スライド内のアニメーションや動画は映らない。字幕は入れない。

渡す前に、少なくとも最初・途中・最後を再生し、スライドの切り替わりと声が合っていること、日本語の書体と画像が崩れていないことを確かめる。
返すときは、ファイルの場所、長さ、解像度、確かめた範囲を伝える。
